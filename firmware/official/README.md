# Official firmware

`buddy_official.bin` is the official Buddy firmware as a merged image (flash at offset 0). Restore it with:

```bash
buddy flash firmware/official/buddy_official.bin --full
```

This image is provided for restoring the official firmware only. It is not open source and not covered by the
Apache-2.0 license of this repository.
